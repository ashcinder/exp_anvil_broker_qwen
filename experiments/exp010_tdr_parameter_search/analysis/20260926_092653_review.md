# 实验10参数搜索完整复核（20260926_092653）

## 结论与覆盖

计划70个唯一试验，成功66个，4个余额试验配置解析失败。成功结果包含330条五方案逻辑记录，对应178个成功的独立缓存执行；重复引用缓存不是重复实验。每组每方案1000笔、单一路由种子7、注入设置120。实际注入105.44～123.79 CTX/s。

已将330条raw_results记录中的Relay、事件、搬运、合计数与各trial的summary.json逐一核对。均为1000笔且完整性、burn校验通过。未修改原始结果。

本批是单因素OAT，不是联合网格；10个维度的单独最优值拼起来没有被验证。
66组中EWMA独占Relay第一8组，但独占R+T第一0组；Plain独占Relay第一53组。R+T为Plain第一65组，硬窗口第一1组（窗口10且TDR完全未启动）。这些计数共享缓存，不是独立胜率估计。

## 固定参考配置

余额1 ETH/broker/分片，16分片、50 brokers；金额筛选0.25～3 ETH；硬窗口4块；
Valve=1.3，Proportional ε=0.1，硬窗口ε=0.2；
EWMA ε=0.5、hl=4、q_min=0.2、χ=2，绝对库存参数0.25 ETH。
以下每个扫描只改变表头指定参数。显式写入默认值的扫描可能重新执行，故“同一默认值”不同表的结果可能不同。
交易金额上下限改变的是筛选集合，不是裁剪交易金额。

## 指标口径

R：走Relay的CTX数；E：开启TDR事件数；T：完成的资金搬运数。
一事件可有多笔搬运；R+E与R+T不是同一成本指标，R+T也不是全链交易数。
本报告给出每个参数值五方案R/E/T及R+E、R+T，未省略不利结果。
只有单次运行，不提供无依据的置信区间、显著性或普遍最优结论。

## 缺失试验的原因

broker.initial_balance_eth被定义为int。命令行覆盖broker.initial_balance_eth=0.75等失败，
可复现报错：ConfigError: expected int, got '0.75'。
四个失败试验ID：
24592d2b6fb9（0.75）、7153a8df5fc0（1.5）、8083bf7678a3（0.5）、c5a44454045a（1.25）。
失败发生在执行前，各自只有Plain启动尝试，没有五方案结果。此次未改共享配置解析器，以免影响运行中的实验；这些点需要修复后补跑。

## EWMA候选与后续验证

- 短负载的低开销候选：ε=0.95、hl=4、q_min=0.2，其余为基线。它胜过本组Valve的R/E/T，但Relay仍比Plain多10笔。
- 长负载当前候选：实验8 ε=0.5、hl=12、q_min=0.6，在已读第一轮Relay7350低于Valve=1.3的7482，但R+T14729高于9888。第二轮与跨轮统计仍需查看。
- 新建实验8独立扫描配置保留上述长负载候选，并增加同hl/q_min的ε=0.85、0.95。后两组是新组合，实验10没有验证过，不声称一定更优。
- Valve完整扫描1.05/1.1/1.2/1.3/1.5/1.7/2/2.5/3，所有结果均须报告；不得只选择较差Valve代表整个方法。
- 最终参数需要在未用于调参的trace窗口及多个种子上复验。只减少Relay与减少总体搬运开销是不同目标。
