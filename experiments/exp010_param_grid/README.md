# exp010 · 定稿方法参数网格全量搜索

**目的**：对手稿版参数扫描（exp003 档案 §9-§11/§18）做**加密 + 加重复**的
全量重搜。全部运行发生在 2026-09-25 出块竞态修复（tx.get_balance 重试）
之后的代码上。编排器模式：复用 exp003 管线，不改任何其它包。

**与旧扫描的关系**：旧数据保留作历史与交叉核对；
论文曲线图改引本包产物（n≥3、口径统一、参数在目录名里）。

## 目录命名规约（参数写进名字）

```
out/<本次发车时间戳>/
├── grid_results.csv                 每臂一行，跑完即追加（中途可查）
├── grid_report.json                 聚合：批次→方案→散点+中位
└── <批次id>__r<场次>/<exp003时间戳>/<方案token>/
     方案 token = 全部参数：topup@37.5@0.35@20.0
     即 策略topup, fund37.5ETH, ε=0.35, hl=20（qmin/chi 省略时为默认）
```

## 判据与记录

- 每臂照常过 gates（G1-G4 + burn≡mint）；本包聚合器把每臂
  gates_ok/burn_ok 记进 CSV，任何 False 都保留现场不掩盖。
- 某场崩溃：CSV 记 aborted 行，批次继续（单场失败不废整批）。
- seed=42 / route_seed=7 全批次冻结：本搜索度量的是同流下参数与时序的效应。

## 运行

```bash
python run.py --dry-run          # 看计划
python run.py                    # 全批次（发车 ~11h）
python run.py --only D1_eps_x_estimator   # 单批补跑/重跑
```
